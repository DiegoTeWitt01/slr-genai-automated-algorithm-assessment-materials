## Purpose
 
The goal of this repository is to support research transparency and
reproducibility by providing access to the materials used during the
planning, selection, extraction, and analysis stages of the review.
 
The SLR investigates the use of Generative AI (LLMs) for the automated
assessment of algorithms and source code in programming education,
including:
 
* Generative AI models and techniques employed
* Assessment instruments and metrics
* Types of feedback generated
* Alignment with active/formative assessment principles
* Challenges, limitations, and ethical aspects reported
 
## Repository Structure
 
```
/protocol          Parsifal research protocol (PICOC, RQs, criteria)
/search-strings    Search queries adapted for each database
/selection-process Selection funnel and quality assessment sheets
/data-extraction   Extracted data from the 40 primary studies
/figures           Charts used in the report/article
```
 
## Methodological Context
 
The review follows the guidelines by Kitchenham (2004) for systematic
reviews in software engineering and uses the PICOC framework. The
protocol was managed with Parsifal (https://parsif.al).
 
Databases searched: ACM Digital Library, IEEE Xplore, Scopus,
Web of Science, SpringerLink, ScienceDirect, SBC OpenLib.
